# Security Policy

## Supported Versions

Tule is pre-release software. Security fixes are applied to the current version
on the default branch; older snapshots are not maintained as supported releases.

## Reporting a Vulnerability

Report suspected vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/richardspicer/tule/security/advisories/new).

Do not report a vulnerability in a public issue, discussion, pull request, or
other public channel. Avoid including credentials, personal information, or data
that does not belong to you in the report.

Please include enough information to reproduce and assess the problem when it is
safe to do so:

- the affected version or commit;
- the operating system and relevant configuration;
- reproduction steps or a minimal proof of concept;
- the observed and expected behavior; and
- the potential security impact.

Limit testing to systems and data you are authorized to use. Do not degrade the
service, access another person's data, or retain sensitive data while
investigating.

Use public issues for non-security defects and feature requests only.
